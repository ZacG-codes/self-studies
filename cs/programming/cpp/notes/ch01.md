## 1.2 Computer Systems: Hardware and Software

All computers consist of similar hardware and software components

### Hardware

The physical components to a computer
- central processing unit (cpu)
- main memory
- secondary storage devices
- input devices
- output devices

CPUs
- the part that actually run or execute programs
- fetches instructions, follows them, and produces a result (fetch, decode, execute cycle)
- comprised of control unit (CU) and arithmetic and logic unit (ALU)
